# 🌦 AI Weather Forecast App

An AI-based Weather Forecast Application made using Python, Tkinter, WeatherAPI and Machine Learning.

## 🚀 Features

- Live Weather Data
- 10-Day Forecast
- AI Weather Advice
- Rain Prediction using ML
- Auto Detect Location
- Open Location in Google Maps
- Background UI
- EXE Application Support

## 🛠 Technologies Used

- Python
- Tkinter
- WeatherAPI
- Machine Learning
- Scikit-learn
- Pandas
- Requests
- PIL
