# Optional scene photos

The background is a CSS gradient scene chosen from the live weather condition.
To show a photo on top of it, add a file named after the scene:

`clear-day`, `clear-night`, `golden`, `cloudy-day`, `cloudy-night`,
`rain`, `storm`, `snow`, `fog`, `default`

Use `.webp` (preferred) or `.jpg`, e.g. `static/img/rain.webp`, about 1920px wide and under 400 KB.
Only add images you are licensed to use (for example the Unsplash or Pexels licence, or your own photos),
and note the source and licence for each file at the bottom of this README.

If a file is missing or fails to load, the gradient scene stays in place.
